# Запись демо и финальный прогон

## Подготовка

1. Получить от команды разрешённый для демонстрации ролик и проверить его локально. Не отправлять видео сторонним AI или хостингам.
2. Подключить API, пересобрать приложение. Проверить UI-ключ, HTTPS, CORS, ссылки кадров и MOV-кодек. Использовать тестовый ключ, который можно заменить после записи.
3. Открыть UI на боевом URL, убрать уведомления и лишние вкладки. Разрешение экрана 1440×900 или 1920×1080. Не показывать введённый ключ и приватные данные.
4. На macOS запустить локальную запись экрана через Shift+Cmd+5. Сохранить запись локально; не добавлять в git.

## Сценарий — 75–90 секунд

- 0–10 с: назвать задачу, показать загрузку.
- 10–20 с: перетащить MOV, показать имя, размер, нажать «Начать проверку».
- 20–35 с: показать статус; длительное ожидание можно сократить монтажом с подписью «ожидание сокращено».
- 35–50 с: показать точный вердикт и число эпизодов.
- 50–65 с: нажать таймкод, показать перемотку плеера, увеличить реальный кадр, закрыть Escape.
- 65–80 с: показать документ, цитату и открыть источник.
- 80–90 с: показать дисклеймер и «Новая проверка».

Если API не готов, запись допускается только как «Демонстрация интерфейса на вымышленных данных». Не называть её анализом видео. Не имитировать реальные кадры или нормы.

## Дополнительная проверка до записи

Отдельно прогнать ролик без нарушения, несколько эпизодов, длинный ролик, неверный ключ, потерю сети, неподходящий файл и мобильную ширину. Попросить человека вне команды пройти путь без подсказок. Обнаруженные ошибки исправить до финального прогона.

## Что ещё нельзя подтвердить без команды

Боевой URL, истинность выдачи ML, точность нормативных ссылок, пять одновременных загрузок, время реального анализа и работа моделей офлайн. Не озвучивать эти пункты как достигнутые без проверки.
