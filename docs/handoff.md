# Передача фронтенда команде

Готов React/Vite/TypeScript UI: загрузка MOV/MP4 до 200 МиБ, статус и процент обработки, точные русские вердикты, плеер и таймлайн, карточки с JPEG и нормативными основаниями. Стилистика Forte, локальные шрифты, интерактивные частицы с выключателем и reduced motion.

HTTP-клиент адаптирован к backend/app/schemas.py в main: verdict=violation/no_violation, evidence_frames=[{timestamp_sec,image_base64}], progress=0..1. Проверка и нормализация находятся в frontend/src/api-contract.ts; контрактные тесты — frontend/tests/.

## Подключение

Нариман: предоставить HTTPS-адрес и отдельный UI-ключ из API_KEYS. В prod можно раздавать frontend/dist через существующий FRONTEND_DIST. При отдельном домене нужен VITE_API_BASE_URL. Сборка production по умолчанию использует API на том же домене, dev без настроек показывает локальную демонстрацию.

Командный Dockerfile пока не включает frontend/dist; для Docker-сдачи сборку нужно добавить на стороне деплоя. Инструкция находится в frontend/README.md.
