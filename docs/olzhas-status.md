## Проверка и границы объёма

Воспроизводимые команды установки PyYAML в отдельное окружение — в [README нормативной базы](../kb/legal/README.md). `tools/validate_legal_kb.py` проверяет структуру JSON / YAML, текстовые SHA256, точность цитат, исторический индекс якорей, исключения, политику 27/5 и шаблоны. `tools/check_legal_catalog.py` проверяет изолированную копию без `data/` и отклонение синтетически повреждённых вариантов. Текущая нормативная проверка прошла: 8 источников / 14 кандидатов / 32 аналитические записи / каталог 27/5, все 27 отрицательных сценариев отклонены. Реальный загрузчик `main` (база `f50a957`, включает PR39 `129ebf2`) получил 27 типов / 26 правил, сохранил активный Т04 без правила; все 27 шаблонов прошли синтетический рендер, fallback 0, исключённых активных типов 0. В каталоге 46 цитат (26 основных + 20 дополнительных), в аналитическом слое 82 + 6 переходных цитат. SHA проверяемой версии фиксируется в сообщении передачи.

Без HTML эти проверки не повторяют извлечение DOM, не подтверждают живые якоря и доступность официальных страниц. Исторические хеши загруженных HTML / инфокарточек и даты футера сохранены как происхождение. Актуальность и применимость нормы к дате конкретного события устанавливаются отдельно.

Технический аудит датасета сохранён отдельно в ветке `codex/dataset-intake-tools`: `tools/audit_dataset.py`, `tools/check_audit_dataset.py`, `docs/data-intake.md`. Эти материалы вынесены из PR32; нормативные проверки от них не зависят. Частные данные и разметка не публикуются.

Порядок сопоставления: **официальный текст → субъект / условия → наблюдаемый признак → подтверждённая привязка**. Принятие каталога не означает готовый детектор. Backend, frontend и ML здесь не изменяются. Контракт сохраняет два вердикта `no_violation` / `violation`; отсутствие `rule` само по себе вердикт не меняет.

По разделу 7 ТЗ облачным AI запрещено передавать видео, кадры или их описания. Нормативная проверка их не использует. В этой ветке не добавляются новые частные наблюдения, материалы видео или таймкоды; исторические `examples` сохранены. Issues не закрываются автоматически.
