## Выполненные проверки

Проверка интеграции с GitHub `main`: 39 тестов репозитория и 37 изолированных тестов загрузчика / сборщика прошли. Это проверки контракта и mock-поведения, не боевой QA. Подробности и таблица runtime ID — в [документе интеграции](catalog-integration.md).

- `python3 -B tools/audit_dataset.py`: код 0, 0 ошибок, 3 предупреждения — два `duplicate_file_content` и один `duplicate_content_multiple_timestamps`. Канонический `data/audit/intake.json` пересоздан текущей версией. Все 32 общих ID / названия / нормативные ссылки DOCX и JSON совпали; реестры и структурные ID 18 + 24 совпали с 42 входами. Длительности взяты из manifest после проверки SHA256, не измерены нами.
- `python3 -B tools/check_audit_dataset.py`: синтетические проверки русских минут / секунд, коллизий X / Х, нескольких таймкодов и конфликтов бинарных меток для одинакового содержимого, hash-gated bounds, размеров, строгих строк-массивов и запрета исполнения стороннего кода прошли.
- `python3 -B tools/validate_legal_kb.py` с PyYAML 6.0.3: код 0; 8 источников, 14 кандидатов, 32 аналитические записи, 27 активных и 5 исключённых типов. Проверены полные тексты, SHA256 HTML / инфокарточек, якоря, 81 цитата типов, 6 переходных цитат, 48 цитат каталога и даты футеров.
- `python3 -B tools/check_legal_catalog.py`: изолированная копия `kb/` без `data/` прошла; все 14 ошибочных вариантов отклонены. Проверены повреждение цитаты, включение исключённого типа, выдуманный `rule` Т04, неверное основание Т13, перенос порога на уход, объединение двух описаний Т06, представление порога как нормы, потеря исключения упаковки, категорический шаблон, повторный YAML-ключ и небезопасный YAML-тег; дополнительно — отключение Т04, переименование runtime ID и ложная аттестация проверяющего. Также проверено отдельное заполнение двух ветвей шаблона Т06.
- На предыдущем этапе 13 отрицательных сценариев JSON-валидатора на временной копии отклонены: повреждённые цитата / якорь / источник, enum, повторный / отсутствующий ID, лишнее поле per-video, неверный runtime-статус, устаревший статус кандидата, переходная цитата, SHA256 HTML / карточки, дата среза. Текущий каталог не меняет исходные HTML / инфокарточки.

Проверки первоначального каталога выполнены bundled Python с изолированным PyYAML через `PYTHONPATH`; интеграционная проверка использует отдельное временное окружение с зависимостями main и PyYAML. Глобальное окружение не менялось. Воспроизводимые команды установки зависимости в отдельное окружение — в [README нормативной базы](../kb/legal/README.md). Проверки каталога не читают `data/` и не запускают авторский пакет анализа.

Порядок проверки: **официальный текст → субъект / условия → наблюдаемый признак → подтверждённая привязка**. Принятие каталога не означает готовый детектор. Backend, frontend и ML остаются за владельцами; их интеграция и QA здесь не выполнялись. Контракт сохраняет два вердикта `no_violation` / `violation`; отсутствие `rule` само по себе вердикт не меняет.

По разделу 7 ТЗ облачным AI запрещено передавать видео, кадры или их описания. Видео / звук не декодировались, изображения не открывались; скрипты авторского пакета только статически разобраны. Исходники, частные наблюдения и аудит находятся в игнорируемом `data/`; DOCX ТЗ и PDF плана в Git не копировались. Исходные файлы и метки не исправлялись, `.DS_Store` не удалялись. Передача подготовлена отдельной веткой от актуального `main`; исходная папка с данными сохранена, публичные файлы дополнительно архивированы.
