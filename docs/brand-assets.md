# Материалы оформления Forte

Источник оформления: https://forte.kz/ru, просмотрено 17.10.2026.

Логотип `frontend/public/forte-logo.svg` извлечён из первого inline-SVG в HTML главной страницы. Сохранён оригинальный viewBox 0 0 101 30 и цвет #A31551; пропорции отображения сохранены. Это фирменный знак банка, а не собственный логотип команды.

Изученный CSS:
https://forte.kz/_next/static/chunks/1aluifwpkd4wx.css

Файлы Open Sans:
- https://forte.kz/_next/static/media/7cdbb9ca823c0a73.p.1h6d36qg8q9eb.woff2 — кириллица.
- https://forte.kz/_next/static/media/cf514f5d0007dafa.p.1wc2mf9hp9pav.woff2 — латиница.

Лицензия Open Sans сохранена вместе с файлами:
https://raw.githubusercontent.com/google/fonts/main/ofl/opensans/OFL.txt

Материалы находятся в frontend/public и копируются Vite в dist. Для загрузки логотипа и шрифтов при использовании приложения интернет не требуется. Данные пользователя этим источникам не отправляются.
