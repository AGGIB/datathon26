# Приём и технический аудит данных

Аудит сверяет метки, технические имена, SHA256 и согласованность необязательного авторского пакета. Он не декодирует видео, кадры или звук, не исполняет скрипты автора и не подтверждает события либо юридическую применимость. Входные файлы не изменяются; отчёт записывается только в игнорируемый `data/audit/`.

Этим PR не добавляются видео, кадры, частные описания клипов или реальные отчёты аудита. Существующее содержимое других частей репозитория этим утверждением не характеризуется.

## Запуск по README

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r tools/requirements-audit.txt
.venv/bin/python -B tools/audit_dataset.py
```

По умолчанию используются `data/open/open_labels.xlsx` и `data/open/videos/`, как в [README](../README.md). Ожидаемое число записей по умолчанию — 42; для другого набора задаётся `--expected-count`. Настраиваются `--labels`, `--videos` и `--output` (по умолчанию `data/audit/intake.json`). Аудит использует активный лист, как `ml.labels.load_labels`; `--sheet` может только явно подтвердить его имя.

Единственный разборщик таймкодов, нормализатор имён и загрузчик XLSX — [ml/labels.py](../ml/labels.py), включая исправления PR37. Аудит добавляет проверки заголовка, полноты строк и допустимых бинарных флагов. Полностью пустые строки пропускаются с предупреждением, частично заполненные дают ошибку. Собственных копий разбора времени нет.

Пакеты закреплены в [requirements-audit.txt](../tools/requirements-audit.txt): `openpyxl==3.1.5` и `python-docx==1.2.0`. У обоих поле `License` в metadata проверенных установленных дистрибутивов — **MIT**. Лицензионные сведения воспроизводятся через `importlib.metadata.metadata("openpyxl")["License"]` и `importlib.metadata.metadata("python-docx")["License"]`. `python-docx` загружается только при запросе DOCX, до хеширования входов; отсутствующий модуль указывается безопасным именем.

## Необязательный авторский пакет

`--manifest`, `--taxonomy`, `--report-data`, `--visual-first` и `--visual-second` по умолчанию не заданы. Отсутствующие секции явно помечаются `status: skipped`; для аудита меток, файлов и дубликатов они не нужны. Если путь запрошен явно, недоступный или некорректный вход даёт exit 2 с безопасным ключом входа. DOCX и JSON могут проверяться отдельно; сравнение представлений без второго источника помечается пропущенным.

Пример полного локального запуска:

```sh
.venv/bin/python -B tools/audit_dataset.py \
  --manifest /local/package/manifest.json \
  --taxonomy /local/package/types.docx \
  --report-data /local/package/report_data.json \
  --visual-first /local/package/visual_first.json \
  --visual-second /local/package/visual_second.json
```

Пути внутри `manifest.file` не открываются: используется только техническое имя. Длительность из manifest применяется для проверки границ таймкода лишь после совпадения SHA256. Аудит не измеряет длительность и не уточняет приблизительную метку. Без подтверждённого manifest проверка границ остаётся `unverified`.

Числа и описание происхождения авторского анализа не дублируются здесь: источник — [analysis-import.md из PR30](https://github.com/AGGIB/datathon26/blob/9e4ab706e45a4ba5f317433e770daef3aa0382c3/docs/analysis-import.md). Группировка train / validation / test по SHA256 уже реализована в [PR30](https://github.com/AGGIB/datathon26/pull/30); до его слияния это ссылка на отдельную реализацию, а не заявление о наличии её кода в main. Аудит не заменяет импорт и оценку модели и самостоятельно не меняет split.

[Нормативный review](type-legal-review.md) и [каталог](../kb/violations.yaml) доступны после слияния PR32: 27 активных индикаторов, 5 исключённых. Аналитические записи, принятие индикаторной политики и фактическая реализация детектора — разные состояния. Совпадение DOCX / JSON не превращает авторскую гипотезу в gold-разметку.

## Дубликаты, ошибки и предупреждения

Одинаковый SHA256 с противоположными бинарными метками — `duplicate_content_label_conflict`, **ошибка**, exit 1. Одинаковое содержимое с одним вердиктом и разными таймкодами остаётся предупреждением: единственное правильное время автоматически не выбирается.

Предупреждения:

- `duplicate_file_content` — группы одинаковых байтов;
- `duplicate_content_multiple_timestamps` — группы с разными заданными таймкодами;
- `missing_manifest_hash` — отсутствует эталонный SHA256;
- `package_script_ast_error` — авторский скрипт нельзя статически разобрать;
- `blank_label_row` — полностью пустая строка XLSX;
- `unexpected_file_in_videos` — неподдерживаемые файлы или каталоги, с агрегатом по расширению без имён файлов.

В stdout выводятся только счётчики, коды проблем и статусы секций, включая число групп дублей и конфликтующих таймкодов; ID, метки отдельных клипов и описания туда не выводятся. Диагностика невозможного запуска содержит только безопасный ключ входа / имя модуля и фиксированный код. Детальный JSON остаётся локальным.

Exit 0 означает отсутствие ошибок (предупреждения допустимы); exit 1 — ошибки сверки; exit 2 — невозможность аудита, неверный вход, зависимость или запрещённый путь. `--output` ограничен JSON внутри `data/audit/`: traversal, symlink-компоненты и пересечение с входами отклоняются. Запись атомарная. Streaming SHA256 и повторная сверка состояния ловят изменение файла во время чтения, замену файла, изменение входного документа или каталога за время аудита.

## Синтетические проверки

```sh
python3 -m pip install -r requirements-dev.txt
python3 -m pytest tools/tests/test_audit_dataset.py ml/tests/test_labels.py -m "not slow" \
  --cov=tools.audit_dataset --cov-report=term-missing --cov-fail-under=80
python3 -B tools/check_audit_dataset.py
```

Pytest собирает `tools/tests` через `testpaths`. Проверяются сквозные XLSX / DOCX exit 0 / 1 / 2, общий загрузчик, optional/skipped, конфликты SHA256 / меток, времена и границы manifest, пустые / частичные строки, безопасные ошибки зависимостей до хеширования, traversal / symlink / alias вывода, изменение входа и файла во время аудита. Все данные этих тестов синтетические; MOV-фикстуры содержат произвольные байты и не декодируются. QA сервиса #25 и реальные видео в эти проверки не входят.
