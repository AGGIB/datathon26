# frontend/ (владелец: Рамазан)

React + Vite + TypeScript. Проект создаётся здесь (`npm create vite@latest . -- --template react-ts`).

## Что нужно от UI

1. **Загрузка.** Файл перетаскивается мышью или выбирается кнопкой. Принимаем `.mov` (и `.mp4`) размером до 200 МБ, показываем прогресс отправки.
2. **Статус.** Каждые 2 с запрашиваем `GET /api/v1/jobs/{id}` и показываем `stage` и `progress`. Для `failed` выводим текст из `error`.
3. **Результат.**
   - Вердикт дословно по ТЗ: «Нарушение не обнаружено» или «Обнаружены признаки возможных нарушений».
   - Плеер исходного видео через `URL.createObjectURL(file)`, под ним таймлайн с метками в `timecode_sec`. Клик по метке перематывает видео.
   - Карточка на каждое нарушение: `type`, таймкод, `description`, `evidence_frames` (1–3 кадра, по клику увеличиваются), блок «Основание» из `rule` (`document`, `clause`, `quote`, ссылка `url`).
   - Дисклеймер: «Результат — подсказка для проверяющего, а не окончательное заключение».

## API

- Формат запросов и ответов описан в [docs/contracts.md](../docs/contracts.md), раздел К1.
- Ключ: заголовок `X-API-Key`. Значение берём из переменной окружения сборки `VITE_API_KEY` (это UI-ключ, второй в `API_KEYS`).
- В разработке: запусти бэкенд на mock (см. корневой README), в `vite.config.ts` укажи `server.proxy: { '/api': 'http://localhost:8000' }`.
- В проде бэкенд сам раздаёт `frontend/dist`, если задана переменная `FRONTEND_DIST`. Тогда UI и API на одном домене, CORS не нужен.
- Чтобы увидеть экран «нарушений нет», загрузи файл, в имени которого есть `clean`.
