# kb/ — база знаний о нарушениях

| Файл | Что | Владелец |
|---|---|---|
| `violations.yaml` | К3: каталог типов нарушений с признаками, шаблонами описаний и нормами | Алпамыс (типы), Олжас (нормы) |
| `annotations.csv` | К4: разметка всех 42 видео | Алпамыс |
| `sources.md` | Найденные НПА: название, номер и дата, URL, какие пункты используем | Олжас |

## annotations.csv: колонки

| Колонка | Пример | Что писать |
|---|---|---|
| `video` | `X-1` | Только латинская `X` (в датасете встречается кириллическая `Х`) |
| `type_id` | `cashier_left_open_safe` | `id` из `violations.yaml`; для видео без нарушений — `none` |
| `t_start` / `t_end` | `20.5` / `31.0` | Начало и конец события, секунды |
| `t_peak` | `22.0` | Самый показательный момент: отсюда берём кадр-доказательство |
| `actor` | `cashier` / `client` / `collector` / `other` | Кто совершает действие |
| `what_visible` | `кассир встаёт и уходит, дверца сейфа открыта` | Только наблюдаемое |
| `angle_id` | `A` | Ракурс камеры: A, B, C… Одинаковый ракурс — одинаковая буква |
| `comment` | | Сомнения, неочевидные моменты |

Одна строка — одно событие. Если в видео два нарушения, делаем две строки.
Для 19 видео без нарушений тоже заполняем строку (`type_id = none`): описываем, что происходит правильно.
